# Web Application - CSCI390 Project Phase 2

A responsive Multi-Utility Frontend Web Application developed using ReactJS for the CSCI390 Web Programming course. This platform consolidates an automated Election Management Dashboard and a dynamic Bill Calculator into a single, seamless user experience.

##  Live Deployment
* **Live Demo URL:** [https://liu-election-project.vercel.app/]

##  Key Features
* **At Least 4 Dedicated Navigation Views:** Home, Election Management, Bill Calculator, and About & Contact.
* **Election Management System:** Dynamic candidate registration, local state-driven voting ballot casting, real-time leaderboard update standings, and audit logging.
* **Bill Calculator Utility:** Accurate financial cost-splitting calculations with customized tip adjustments and input safety metrics.
* **Modern Responsive Design:** Completely styled from scratch with fluid grid boundaries for desktop and mobile devices.

##  Built With
* ReactJS (Functional Components & Hooks)
* HTML5 / CSS3 (Inline Adaptive Styling)
* JavaScript (ES6+)
